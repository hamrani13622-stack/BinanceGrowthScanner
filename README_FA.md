# اسکنر رشد رمزارز — اندروید

این پروژه سورس یک اپلیکیشن Android بومی است که داده‌های عمومی Binance Spot را دریافت می‌کند، حداکثر ۳۵ جفت‌ارز USDT نقدشونده را اسکن می‌کند و سیگنال‌ها را با امتیاز، حد ضرر و دو هدف تقریبی نشان می‌دهد. برنامه سفارش خریدوفروش ثبت نمی‌کند و کلید API لازم ندارد.

## ساخت APK
این محیط فایل سورس را آماده می‌کند؛ APK کامپایل‌شده در این بسته وجود ندارد. برای ساخت APK از Android Studio استفاده کن:

1. Android Studio را نصب کن (نسخه‌ای که از Android Gradle Plugin 8.7.3 و SDK 35 پشتیبانی کند).
2. پوشه `BinanceGrowthScannerAndroid` را از طریق **Open** باز کن.
3. اجازه بده Gradle sync شود و اگر خواسته شد Android SDK Platform 35 را نصب کن.
4. گوشی را با USB وصل کن و USB debugging را فعال کن، یا از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** فایل APK بساز.
5. خروجی debug معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
6. برای نصب مستقیم، APK را به گوشی منتقل و باز کن. ممکن است لازم باشد به برنامه‌ای که فایل را باز می‌کند اجازه «Install unknown apps» بدهی.

## استفاده
- برنامه را باز کن و مجوز اعلان‌ها را بده.
- روی «شروع اسکن» بزن.
- برنامه قیمت‌ها و کندل‌های ۴ ساعته را از API عمومی بایننس دریافت می‌کند.
- امتیاز ۶۵ به بالا به‌عنوان سیگنال قابل توجه نمایش داده می‌شود و برای بهترین نتیجه واجد شرایط یک اعلان محلی می‌سازد.

## محدودیت مهم اعلان‌ها
در این نسخه اعلان‌ها هنگام اجرای اسکن دستی ارسال می‌شوند. اسکن پس‌زمینه‌ی زمان‌بندی‌شده هنوز پیاده‌سازی نشده است؛ اندروید برای کار پایدار در پس‌زمینه به WorkManager یا یک سرور نیاز دارد و صرف نصب APK تضمین نمی‌کند که اسکن دائمی انجام شود. اگر اعلان خودکار حتی وقتی برنامه بسته است لازم داری، باید در نسخه بعدی WorkManager/سرور اضافه شود. برای اعلان از راه دور در زمان خاموش بودن برنامه، سرور پایدار معمولاً قابل‌اعتمادتر است.

## امتیازدهی
- قیمت بالاتر از EMA20: +10
- EMA20 بالاتر از EMA50: +15
- قیمت بالاتر از EMA200: +10
- RSI بین 52 تا 68: +15؛ RSI بین 45 تا 52: +7
- حجم کندل آخر بالاتر از 1.5 برابر میانگین ۲۰ کندل: +20؛ بالاتر از 1.2 برابر: +10
- بازده مثبت ۷روزه: +10
- شکست سقف ۲۰ کندل قبلی: +20
- RSI بالاتر از 75: −15
- ATR بالاتر از ۸٪ قیمت: −10

حد ضرر اولیه بر اساس بزرگ‌ترِ ۲×ATR یا ۲٫۵٪ قیمت محاسبه می‌شود. اهداف برابر ۱٫۵ و ۲ برابر فاصله ریسک هستند.

## مدیریت ریسک
- این اپ ابزار تحقیق است، نه توصیه مالی شخصی یا تضمین سود.
- امتیاز ۰ تا ۱۰۰، احتمال آماری رشد نیست.
- ابتدا سیگنال‌ها را در حالت آزمایشی ثبت و ارزیابی کن.
- ریسک هر معامله را ترجیحاً به ۰٫۵ تا ۱٪ سرمایه محدود کن.
- لغزش قیمت، کارمزد، نقدشوندگی و گپ‌ها ممکن است حد ضرر را بدتر از قیمت مشخص‌شده اجرا کنند.
- این نسخه API عمومی را مصرف می‌کند و هیچ API key یا دسترسی معاملاتی ندارد.
